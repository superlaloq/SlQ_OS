# Identidad visual de SlQ

La interfaz conserva la paleta ya usada en `styles.css`: fondo azul-negro
(`#090d14`), violeta (`#8b7cff`) y menta (`#58dfc0`), con lavanda clara para
contraste. Las marcas e iconos son SVG originales y editables, sin dependencias
de fuentes o servicios externos.

- `slq-os-icon.svg`: simbolo compacto para la marca SlQ-OS.
- `slq-os-mark.svg`: marca principal abstracta para el portal SlQ-OS.
- `slq-ai-mark.svg`: simbolo abstracto de nodos para el paquete SlQ_IA.
- Los iconos de categorias se dibujan como SVG en `frontweb/app.js`.

La atribucion de marca del proyecto es **SlQ, desarrollada por Eduardo
Barría**. Evitar copiar logotipos o personajes de terceros; estas piezas son
una interpretacion original de la direccion visual del proyecto.
