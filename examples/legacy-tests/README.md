# Pruebas SlQ archivadas

Estos scripts sueltos se conservaron al ordenar la raiz del proyecto. Son
ejemplos historicos, no la suite de pruebas activa. Algunos pueden escribir o
eliminar archivos en el directorio de trabajo desde el que se ejecutan; leelos
antes de probarlos.

Las pruebas mantenidas del proyecto estan en `test/` y se ejecutan con
`npm test`.
